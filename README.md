# Sales Data Filter & Report Engine

## Objective
Analyze annual sales across 10 stores and 12 months using NumPy.

## Features
- Annual sales simulation
- Quarterly sales analysis
- Monthly sales reports
- Store-wise performance analysis
- Boolean masking
- Fancy indexing
- Sales target comparisons

## Technologies
- Python
- NumPy
- Google Colab

## How to Run
Open `Sales_Data_Filter_Report_Engine.ipynb` in Google Colab and run the cells from top to bottom.
